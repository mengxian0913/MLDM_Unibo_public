Part A — The ablation study¶

A0. What an ablation study is¶

The word. In neuroscience, an ablation is the removal of a part of the brain, to see which behaviour is lost. In machine learning the term was borrowed for an experiment on a system made of several parts: remove one component, retrain, measure again. The drop in performance is the contribution of that component — in the presence of all the others.

What can be a component.

kind examples on NordicMart
input attributes, single or in groups recency; the pair sessions + store_only
preparation steps the log of the spend, the indicator columns, standardization
parts of the algorithm bootstrap and random attribute subsets in a forest; shrinkage in boosting
regularizers the minimum leaf size of a tree; the learning rate of boosting
size of the ensemble number of trees

The protocol.

  1. A baseline: the full system, as it would be delivered.
  2. One variant per component, with that component removed (or switched off) and everything else identical: same data, same folds, same measure, same random_state.
  3. Every variant is retrained from scratch and evaluated with cross-validation on the training part (the test set stays closed: an ablation is part of building the model, Lecture 10a).
  4. Report the difference from the baseline, fold by fold, and how consistent it is.

Why fold by fold. The five CV scores of a model differ from each other for two reasons:

  • the fold: each fold has different test records, and some folds happen to be harder than others for every model (e.g. a fold with many churners that behave like loyal customers);
  • the model: what we actually want to measure.

The first reason is shared: if fold 3 is hard, it is hard for both variants, and both scores go down together. So the standard deviation of the five scores of one model mostly measures how different the folds are, not how good the model is. Comparing two models through "mean ± std" mixes the two reasons, and two clearly different models can look indistinguishable.

The remedy is to compare the two scores of the same fold, and only then average. A small invented example with three folds:

fold 1 fold 2 fold 3 mean ± std
variant A 0.80 0.70 0.90 0.80 ± 0.08
variant B 0.82 0.73 0.91 0.82 ± 0.07
B − A +0.02 +0.03 +0.01 +0.02 ± 0.01

The two intervals overlap widely (0.72–0.88 and 0.75–0.89): taken separately, A and B seem equivalent. But fold by fold, B beats A every time, by 0.01–0.03: the large ups and downs (0.70 vs 0.90) belong to the folds and cancel in the difference. The noise of the difference (± 0.01) is much smaller than the noise of each score (± 0.08) because the two scores move together. In formulas: $\mathrm{Var}(B - A) = \mathrm{Var}(A) + \mathrm{Var}(B) - 2\,\mathrm{Cov}(A, B)$, and the covariance is large when the folds dominate.

This is called a paired comparison: each fold gives a pair of scores measured on the same test records, as when a treatment is judged by measuring the same patients before and after rather than two different groups. It works only if every variant uses exactly the same folds: this is why cv_n is created once, with a fixed random_state, and passed to every call. In A1 you will check all this on the real numbers of NordicMart.

Reading the result.

  • large drop, the same sign on every fold → the component matters;
  • difference ≈ 0 → the component can be removed: a simpler system, same performance;
  • a rise → the component hurts: remove it.

Three pitfalls (we meet all three today).

  • Redundancy: two components carry the same information; removing either one shows nothing, removing both shows a lot. Ablate groups too.
  • Interactions: the effect of removing A depends on whether B is there. Effects are not additive: a 2 × 2 design (with/without A × with/without B) shows it.
  • Scope: an ablation measures what this model, trained in this way, gets from a component. It is not a statement about the world ("recency causes churn"), and another model may use the same attribute differently.

Ablation vs the importances of Lecture 13. Permutation importance shuffles a column and does not retrain: it measures how much a fitted model relies on that column. A drop-column ablation retrains without the column: it measures how much the learning needs it — if another column can replace it, the drop is small. Both are useful; they answer different questions.
